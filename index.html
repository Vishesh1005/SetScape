Chapter 01

Introduction

Before the symbols, the story — because set theory didn't arrive fully formed. It was born out of one mathematician's obsession with a very strange question: are some infinities bigger than others?

A brief history

In 1874, German mathematician Georg Cantor was working on trigonometric series when he stumbled into a much bigger problem: how do you compare the "size" of infinite collections? His answer — that you could put two infinite sets into one-to-one correspondence to compare them — led him to a genuinely shocking discovery: the real numbers are "more infinite" than the natural numbers. Not all infinities are equal.

This idea was controversial. Fellow mathematician Leopold Kronecker fiercely opposed treating infinite sets like finite ones. But Cantor's framework survived the pushback and, by the early 1900s, set theory had become the language other mathematicians used to build everything else — numbers, functions, geometry, all of it, redefined in terms of sets.

Did you know?

In 1901, philosopher Bertrand Russell found a genuine hole in naive set theory: consider "the set of all sets that do not contain themselves." Does it contain itself? Either answer leads to a contradiction. This became known as Russell's Paradox, and it's why modern set theory is built on careful axioms (Zermelo–Fraenkel, 1908) rather than the free-form "any collection is a set" approach Cantor started with.

Why sets matter

Sets aren't just a chapter you get through before "real" math starts — they're the substrate underneath most of it. Relations, functions, probability, and even numbers themselves can all be formally built out of nothing but sets.

CS Connection

If you've ever written SELECT * FROM customers UNION SELECT * FROM leads, used a Python set() to remove duplicates, or typed a Google search with multiple keywords, you were doing set theory without necessarily naming it. Chapter 9 goes deep on this.

Real-life examples

A library's catalogue is a set of books. Your phone's contact list is a set of people. The students who show up to a 9am lecture form a set — and the students who show up and submitted their assignment form the intersection of two sets. You already think in sets; this chapter just gives that thinking a formal vocabulary.

Chapter 02

Elementary Set Theory

Every formal system starts with a definition precise enough to build on. Here's set theory's.

Definition

A set is a well-defined collection of distinct objects. "Well-defined" means that for any object, you can say with certainty whether it belongs to the set or not — no ambiguity allowed.

The "well-defined" test

This single word — well-defined — is what separates a set from a vague grouping. "The vowels in the English alphabet" is a set: for any letter, you can say definitively whether it's a vowel. "The best movies of all time" is not a set: whether a particular film belongs depends entirely on who you ask.

Common mistake

Students often assume any grouping counts as a "set" in casual conversation. In mathematics it only counts if membership is objectively decidable — subjective categories (best, worst, most interesting) don't qualify.

Membership notation

Sets are conventionally named with capital letters (A, B, C…) and their elements with lowercase letters. Membership is written with the Greek symbol ∈ ("belongs to") and its negation ∉ ("does not belong to").

a ∈ A  →  "a belongs to A"
b ∉ A  →  "b does not belong to A"

Two ways to represent a set

Every set can be written in one of two equivalent forms:

Roster (tabular) form — list every element
All elements are listed explicitly, separated by commas, inside curly braces. Order doesn't matter and repeats collapse to one.
e.g. The set of vowels: V = {a, e, i, o, u}
e.g. Odd numbers under 10: O = {1, 3, 5, 7, 9}
Set-builder form — describe the defining property
Instead of listing elements, you state the rule every element must satisfy: {x : condition on x}. Read the colon as "such that."
e.g. V = {x : x is a vowel in the English alphabet}
e.g. A = {x : x is a natural number and 3 < x < 10} → this describes {4, 5, 6, 7, 8, 9}
Remember

Set-builder form is essential for infinite sets you can't fully list — like {x : x is a real number} — while roster form works best for small, finite, or clearly-patterned sets.

Chapter 03

Types of Sets

Not every set looks the same. This chapter builds the vocabulary you'll use constantly for the rest of the book.

Empty & Singleton Sets

Definition

The empty set (or null set), written ∅ or {}, contains no elements at all. A singleton set contains exactly one element — e.g. {5}.

The empty set isn't "nothing" in a casual sense — it's a perfectly well-defined set, just one with zero members. Example: {x : x is a natural number and 1 < x < 2} is the empty set, because no natural number satisfies that condition.

Finite & Infinite Sets

Definition

A set is finite if its elements can be completely counted — the counting process reaches an end. Otherwise it's infinite.

{a, e, i, o, u} is finite — 5 elements, full stop. The set of natural numbers ℕ = {1, 2, 3, …} is infinite — the "…" is doing real work there, signaling the pattern continues forever with no final element.

Common mistake

Not every infinite-looking set is actually infinite — check the bounds carefully. {x : x is a natural number and x < 1,000,000} looks huge, but it's finite (exactly 999,999 elements). Infinity is about whether the counting terminates, not about size.

Equal Sets vs. Equivalent Sets

These two get mixed up constantly, so they get their own callout.

Definition

Equal sets have exactly the same elements (A = B). Equivalent sets merely have the same number of elements — their cardinalities match, but the elements themselves can be completely different.

A = {1, 2, 3} and B = {3, 1, 2}  →  Equal (identical elements, order irrelevant)
A = {1, 2, 3} and C = {x, y, z}  →  Equivalent only (same size, different elements)
Exam Tip

Every pair of equal sets is automatically equivalent (same elements ⟹ same count) — but equivalent sets are not necessarily equal. This one-directional relationship is a favorite short-answer question.

Universal Set

In any given problem, the universal set (U) is the "everything under consideration" set — every other set in that context is a subset of U. For a problem about triangles, U might be "all triangles in a plane." For a problem about students, U might be "all students in the school."

Chapter 04

Subsets & Power Sets

Once you can compare two sets element-by-element, "subset" is the natural next question: is everything in A also in B?

Definition

A is a subset of B (written A ⊆ B) if every element of A is also an element of B. If additionally A ≠ B, A is a proper subset of B (written A ⊂ B), and B is called a superset of A.

Remember

Two facts that always hold: every set is a subset of itself (A ⊆ A), and the empty set is a subset of every set (∅ ⊆ A) — including itself.

The classic trap: ∈ vs. ⊆

Common mistake

Given A = {1, 2, {3, 4}, 5}, is {3, 4} an element or a subset? Here, {3, 4} appears literally as one of A's four elements — so {3, 4} ∈ A is true, and {{3, 4}} ⊆ A is also true (a set containing that one element is a subset). But {3, 4} ⊆ A is false — 3 and 4 individually are not elements of A at all. Read every question like this slowly.

Subset checker

Enter two sets to check the relationship between them, both directions.

Intervals as subsets of ℝ

When the universal set is the real numbers, subsets are often written as intervals rather than roster or set-builder form:

(a, b) = {x : a < x < b}  →  open interval, endpoints excluded
[a, b] = {x : a ≤ x ≤ b}  →  closed interval, endpoints included
[a, b) = {x : a ≤ x < b}  →  half-open, a included, b excluded
(a, b] = {x : a < x ≤ b}  →  half-open, a excluded, b included

Power Set

Definition

The power set of S, written P(S), is the set of all possible subsets of S — including ∅ and S itself. If S has n elements, P(S) has exactly 2ⁿ elements.

Power set generator

Enter a small set (4–5 elements recommended) and watch every subset get built.

Worked example: P({1, 2}) step by step
1 Start with the empty set: { ∅ }
2 Add subsets containing 1: { ∅, {1} }
3 Add subsets containing 2 (combine with all previous): { ∅, {1}, {2} }
4 Add the subset containing both: { ∅, {1}, {2}, {1,2} }
✓ Total: 2² = 4 subsets, matching the formula.
Chapter 05

Venn Diagrams

Every operation in the next chapter has a formal definition — but the fastest way to actually understand one is to see it.

Venn diagrams are named after English logician John Venn (1834–1883). The convention is simple and has barely changed in over a century: a rectangle represents the universal set U, and circles inside it represent subsets. Where circles overlap, elements belong to both sets.

Remember

Venn diagrams are a visualization tool, not a proof method — they're excellent for building intuition and checking your work, but a rigorous proof still needs to be written using set-builder notation and logical reasoning (see the miscellaneous proofs referenced in Chapter 7).

Chapter 06

Operations on Sets

Just like addition and multiplication combine numbers into new numbers, these five operations combine sets into new sets. Every one of them is defined below — then you can toggle through all of them live in the diagram.

Interactive Venn visualizer

Click an operation — the diagram and the formal notation both update instantly.

Union (∪)

Definition

A ∪ B = {x : x ∈ A or x ∈ B} — every element in A, in B, or in both, counted once.

Example: {2,4,6,8} ∪ {6,8,10,12} = {2,4,6,8,10,12}. Notice 6 and 8 appear in both original sets but only once in the result.

Intersection (∩)

Definition

A ∩ B = {x : x ∈ A and x ∈ B} — only elements common to both sets. If A ∩ B = ∅, A and B are called disjoint sets.

Example: {2,4,6,8} ∩ {6,8,10,12} = {6,8}.

Difference (−)

Definition

A − B = {x : x ∈ A and x ∉ B} — elements in A with anything also in B removed. Note this is not symmetric: A − B ≠ B − A in general.

Example: {1,2,3,4,5} − {2,4,6,8} = {1,3,5}, while {2,4,6,8} − {1,2,3,4,5} = {6,8}.

Complement (′)

Definition

A′ = U − A = {x : x ∈ U and x ∉ A} — everything in the universal set that isn't in A.

Symmetric Difference (Δ)

Definition

A Δ B = (A − B) ∪ (B − A) — elements in exactly one of the two sets, never both.

Exam Tip

A − B, A ∩ B, and B − A are mutually disjoint — together they exactly tile A ∪ B with no overlap. This is a handy sanity check when solving cardinality problems: |A∪B| = |A−B| + |A∩B| + |B−A|.

Cartesian Product (×)

Definition

A × B is the set of all ordered pairs (a, b) where a ∈ A and b ∈ B. Order matters here: A × B ≠ B × A unless A = B.

Chapter 07

Set Laws

Seven law families that let you simplify set expressions the same way algebraic laws let you simplify equations. These come up constantly in proofs.

Identity Laws   A ∪ ∅ = A    A ∩ U = A

Domination Laws   A ∪ U = U    A ∩ ∅ = ∅

Idempotent Laws   A ∪ A = A    A ∩ A = A

Commutative Laws   A ∪ B = B ∪ A    A ∩ B = B ∩ A

Associative Laws   (A∪B)∪C = A∪(B∪C)    (A∩B)∩C = A∩(B∩C)

Distributive Laws   A∪(B∩C) = (A∪B)∩(A∪C)    A∩(B∪C) = (A∩B)∪(A∩C)

Complement Laws   A ∪ A′ = U    A ∩ A′ = ∅    (A′)′ = A
Exam Tip — De Morgan's Laws

The single most-tested pair in this entire book: (A ∪ B)′ = A′ ∩ B′ and (A ∩ B)′ = A′ ∪ B′. In words: the complement of a union is the intersection of the complements, and vice versa. Named after mathematician Augustus De Morgan.

Seeing De Morgan's Law visually

Rather than take it on faith, compare these two diagrams — they shade the exact same region, proving (A ∪ B)′ = A′ ∩ B′:

A′ ∩ B′

Identical shaded regions → the law holds. The second De Morgan's law (A∩B)′ = A′∪B′ follows the same logic, mirrored.

Chapter 08

Set Combinations (Inclusion–Exclusion)

When you need the exact count of elements across overlapping sets, adding sizes naively double-counts the overlap. This principle corrects for that.

Formula — two sets

|A ∪ B| = |A| + |B| − |A ∩ B|

Formula — three sets

|A∪B∪C| = |A|+|B|+|C| − |A∩B| − |A∩C| − |B∩C| + |A∩B∩C|

For three sets, pairwise overlaps get subtracted once each — but that removes the triple-overlap region three times over, so it has to be added back once at the end to land on the correct count.

Inclusion–exclusion calculator

Adjust the sizes — |A ∪ B| computes live.

Solved: the classic hockey/basketball problem
Q In a class of 40 students, 22 play hockey, 26 play basketball, and 14 play both. How many play neither?
1 |H ∪ B| = |H| + |B| − |H ∩ B| = 22 + 26 − 14 = 34
2 Students playing neither = Total − |H ∪ B| = 40 − 34 = 6
✓ Answer: 6 students play neither sport.
Chapter 09

Applications in Computer Science

This is where set theory stops being abstract. If you've written any of the code below, you were already thinking in sets.

Databases — SQL

UNION and INTERSECT in SQL are literally set union and intersection over query results. A JOIN is a more elaborate relative built on the same idea — combining rows based on a shared condition.

SELECT name FROM customers
UNION
SELECT name FROM leads;
-- returns every unique name from either table
Programming — Python

Python has a built-in set type with union and intersection as actual operators — this is Chapter 6, verbatim, in working code.

A = {2, 4, 6, 8}
B = {6, 8, 10, 12}
A | B  # union → {2,4,6,8,10,12}
A & B  # intersection → {6,8}
A - B  # difference → {2,4}
Data Structures — Hash Sets

A hash set's entire purpose is guaranteeing the set-theory rule that elements are distinct — inserting a duplicate simply has no effect, exactly like {1,2,2,3} collapsing to {1,2,3}.

Search Engines

Searching "discrete AND math" returns the intersection of pages containing "discrete" and pages containing "math." Searching "discrete OR math" returns their union. Boolean search syntax is set notation wearing different symbols.
